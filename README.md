# Site Ultra Center

Site estático feito com HTML, CSS e JavaScript. Não precisa instalar dependências nem compilar.

## Arquivos

- `index.html`: página principal
- `styles.css`: estilos e layout responsivo
- `script.js`: menu móvel e ano automático no rodapé
- `assets/`: fotos das unidades e logomarcas

## Publicar no GitHub Pages

1. Extraia esta pasta.
2. Envie os arquivos e a pasta `assets` para a raiz de um repositório GitHub.
3. No repositório, abra **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch principal e a pasta `/ (root)`, depois salve.

O GitHub Pages publicará o site usando `index.html` como página inicial.
